# Site vitrine Yeee — traiteur pour entreprises

Site statique (HTML/CSS + un petit JavaScript), publié avec GitHub Pages.

## Ce qu'il faut compléter
- Chercher `[À COMPLÉTER]` dans les fichiers `.html` : chaque zone rouge sur le site est une info manquante.
- `assets/script.js`, tout en haut : votre adresse e-mail (`EMAIL_CONTACT`) et la clé Web3Forms (`CLE_WEB3FORMS`).
- Photos : remplacer chaque `<div class="photo">…</div>` par `<div class="photo"><img src="assets/photos/nom.jpg" alt="description"></div>`.

## Fichiers
- `index.html` Accueil · `prestations.html` · `comment-ca-marche.html` · `devis.html` · `contact.html` · `mentions-legales.html`
- `assets/style.css` (couleurs dans le bloc `:root`), `assets/script.js`, `assets/fonts/` (polices hébergées sur le site, sans appel à Google).
